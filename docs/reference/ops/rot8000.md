# ROT8000

Rotate visible Basic Multilingual Plane characters halfway through the list of 63 404 that take part, so applying it twice gives the input back. Spaces, controls and characters outside the BMP are copied.

| Id | Input | Output | Background |
|---|---|---|---|
| `rot8000` | string | string | [Classical ciphers and XOR](../../learn/classical-ciphers.md) |
<!-- /docs:head -->

## How it works

`rot8000` is ROT13 for Unicode. It lists 63 404 characters of the Basic Multilingual Plane in
code point order, leaving out spaces, controls, surrogates and a few invisible format
characters, and moves each one 31 702 places along the list, half of its length. Doing it
twice gives the input back.

**Worked example: `Hello, World!`**

`H` (U+0048) is at index 39 of the list; index 39 + 31 702 is U+7C51 `籑`. Every Latin letter
lands in the CJK ideographs this way, and the space is not in the list, so the result is
`籑籮籵籵籸簵 籠籸类籵籭簪`.

Characters outside the BMP, such as emoji, are copied.

## Use it

**Web app:** [open this example in UniChef](https://0xdolan.github.io/unichef/#/?r=q1YqSy0qzszPU7Iy1FEqLkktKFayiq5Wyi9QslIqyi-xMDAwUNJRSixKB4pX19bG1gIA&i=80jNycnXUQjPL8pJUQQA), or search for "ROT8000" in the operation list.

**CLI:**

```sh
unichef op rot8000 'Hello, World!'
```

**Python:**

```python
from unichef.core.dish import Dish
from unichef.core.runner import run_operation

result = run_operation("rot8000", {}, Dish.of_string("Hello, World!"))
print(result.dish.value)
```

**TypeScript:**

```ts
import { runOperation } from '@unichef/core';

const result = await runOperation("rot8000", {}, { type: 'string', value: "Hello, World!" });
console.log(result.dish.value);
```
