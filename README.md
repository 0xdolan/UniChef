# UniChef

A Unicode-aware data workbench: a recipe pipeline of text and encoding operations, a character database, and security checks for invisible, bidi and confusable characters. It ships as a Python library and CLI, a TypeScript library, an offline web app and browser extensions.

The project is in early development.

## Branches

This repository follows Gitflow: `main` holds releases, `develop` is the integration branch, and work happens on `feature/*`, `bugfix/*`, `docs/*` and `chore/*` branches cut from `develop`.
